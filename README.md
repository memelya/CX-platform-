# ◆ CX Profit Platform

**Аналитическая платформа клиентского опыта для крупного банка.**

Не очередной дашборд NPS. Платформа, которая переводит клиентский опыт в деньги — и показывает, что делать, чтобы заработать больше.

[🌐 Сайт](https://memelya.github.io/CX-platform-)

## Быстрый старт

```bash
npm install
npm run dev
```
